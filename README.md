# Live Web Wallpaper

یک Live Wallpaper اندرویدی کم‌مصرف با سه حالت:

- 🌐 صفحه وب به‌عنوان پس‌زمینه
- 🟢 ماتریکس متحرک
- `</>` صفحه تایپ کد

## امکانات
- تعیین URL
- بزرگ‌نمایی/کوچک‌نمایی صفحه وب
- کم‌رنگ کردن محتوا
- تعیین رنگ پس‌زمینه از چند رنگ آماده
- توقف انیمیشن هنگام غیرقابل‌مشاهده بودن Wallpaper برای کاهش مصرف باتری
- بدون کتابخانه‌های سنگین یا سرویس دائمی جداگانه

## نکته مصرف باتری
صفحه وب ذاتاً بسته به سایت می‌تواند CPU/GPU مصرف کند. برای مصرف کمتر، سایت‌های سبک و بدون ویدئو/انیمیشن پیشنهاد می‌شوند.
